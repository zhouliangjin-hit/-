# 马原研习社 · 单文件离线版

双击本文件夹中的 **马原研习社.html**，用较新的 Edge、Chrome 或 Firefox 打开即可。无需安装 Python、启动 HTTP 服务或联网。

这个 HTML 已包含题库、知识图谱、样式、程序和图片，可以单独复制给同学。`Web/index.html` 是功能相同的文件夹离线版，分享时需要复制整个 `Web` 文件夹。

学习记录保存在当前浏览器中。两个版本、不同浏览器及不同文件路径的记录可能分别保存；换文件、换电脑或升级前，请到「成绩分析」导出学习备份，再在新版本导入。浏览器无法保存记录时，页面会提示，本次仍可正常练习。

此文件由工程生成，请在工程内更新资料和代码后，在工程根目录运行：

```powershell
python Web/tools/build_offline.py
```

仅供公益复习，禁止售卖。
