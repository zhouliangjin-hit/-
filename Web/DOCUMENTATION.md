## 1. 项目背景与素材来源

### 1.1 项目定位

一个面向《马克思主义基本原理》课程复习的**纯静态学习网站**，中文名「马原研习社」。
核心叙事：**以思维导图为纲，以题库练习为目；纲举目张，错题归仓，成绩有析。**

### 1.2 素材清单（用户提供，位于工程 `mindmap/` 与 `questions/`）

| 素材 | 内容 | 在本项目中的去向 |
|---|---|---|
| `README.md`（mindmap 目录） | 指明素材用于「生成动态思维导图」，应含章节结构数据、节点说明、节点关联与跳转规则；markdown 先上传、最后统一转 JSON | **产品蓝本**：思维导图模块 + JSON 化流水线直接按此约定实现 |
| `chapter-01.md` | 马哲第一章课程笔记（导论/本体论/辩证法，多级标题） | 思维导图数据源 → `chapters.json` |
| `Question 第一章 第一节.md` | 课堂小测1+2（判断/单选/多选，含解析） | 题库 `c1s1-q1`、`c1s1-q2` |
| `Question 第一章 第二节&第三节.md` | 21 道选择题 + 1 道材料论述题 | 题库 `c1s23`；材料论述入主观题库 |
| `24秋-Question.md` / `24秋-Answer.md` | 2024 秋一校三区期末回忆卷（单选10/多选5/简答3/辨析2/论述1，附解析与评分要点） | 客观题入库 `final-2024`；主观题入主观题库 |
| `马原考研题（选择）.md` | 71 道考研政治分章真题（含解析） | 题库 `kaoyan`，按章节切片供专练与闯关 |
| `马克思主义基本原理-2024秋-….pdf` | 教材原文（623KB） | 暂作背景资料，未直接入库（见 §7 路线建议） |

### 1.3 技术选型（有意为之的"克制"）

- **零框架、零外部依赖**：原生 HTML/CSS/JS，不引 CDN。`Web/index.html` 与工程根目录 `Offline/马原研习社.html` 都可以直接双击打开，也可静态托管。
- **数据与代码分离**：题目/导图 JSON 由 `tools/parse_sources.py` 生成；`tools/build_offline.py` 生成普通数据脚本和自包含 HTML，维护者更新后统一重新生成。
- **纯本地存档**：学习数据存 `localStorage`，免登录、可导出和导入备份；存储不可用时降级到本次会话内存并持续提示。

## 2. 视觉风格规范（风格）

### 2.1 设计概念

**「书斋纸感 × 思政朱红」**——把"翻旧讲义"的纸墨温度与思政课的仪式感结合：
纸质暖底弱屏幕刺激、朱砂红作主行动色、鎏金作荣誉/成就点缀、衬线标题建立书卷气。
亮暗双主题，同一套 token 两套取值，全部经 CSS 变量切换，无 JS 计算色值。

### 2.2 色彩令牌（CSS 变量，定义于 `assets/style.css :root`）

亮色（默认）| 暗色 | 用途
---|---|---
`--bg:#f5efe3` | `#171411` | 页面底色（纸）
`--card:#fffdf7` | `#25201a` | 卡片面
`--ink:#2b2418` | `#ede4d3` | 主文字（墨色）
`--ink-2:#5f5545` | `#c9bda5` | 次级文字
`--mut:#9a8c76` | `#8f8270` | 弱化/占位文字
`--line:#e4d9c3` | `#3c352a` | 分隔线
`--red:#b3402f` | `#e07655` | **主色·朱砂**：主按钮、当前导航、正确强调
`--red-deep:#8c2f22` | `#c05137` | 主色悬停态
`--red-soft:#f7e5df` | `#40271f` | 主色浅底（选中项、标签底）
`--gold:#b98a2e` | `#d9a94e` | **成就色·鎏金**：星级、解析标题、导图一级节点
`--green:#3f7d4e` | `#6fae7d` | 正确/已掌握
`--blue:#38618f` | `#7ba4d8` | 信息/辅助标签

背景叠加两层极淡的径向渐变（红/金 5–6% 透明度）营造"宣纸纹理"；导图画布铺 26px 点阵。

### 2.3 字体与排版

- 标题（`--font-display`）：`"Noto Serif SC","Source Han Serif SC","Songti SC","STSong","SimSun",serif`（衬线，书卷气；全部走系统字体，无网络字体依赖）。
- 正文（`--font-body`）：系统无衬线栈（PingFang/Microsoft YaHei 优先）。
- 行高：正文 1.65，题干 1.75；题干字号 16.5px 且加粗，保证长材料题可读。

### 2.4 形状、阴影与动效

- 圆角：卡片 `--radius:14px`，小元素 `--radius-sm:9px`，按钮/胶囊 999px。
- 阴影：双层暖棕投影（`--shadow-sm/--shadow`），暗色下换深黑投影。
- 动效约定：hover 上浮 `translateY(-1~-4px)` 或轻微放大；答错选项 `shake` 抖动 0.3s；星星入场无动画避免干扰；**尊重 `prefers-reduced-motion`**（全部动画禁用）。
- 加载屏：朱砂五角星 `clip-path` 旋转脉冲。

### 2.4a 装饰元素：马恩版画素描（v1.1 新增）

- **素材**：`assets/marx-engels.png` —— 马克思与恩格斯双侧面胸像，版画/线刻（woodcut）风格；
  生成后经 Pillow 处理为**透明底**（白底→alpha，墨迹越深越实），898×900。
- **两处用法**：
  1. `body > .ink-watermark`：全站固定水印，右下角半出血（`right:-3vw; bottom:-10vh`），
     宽度 `clamp(300px,36vw,540px)`，亮色不透明度 5.5%，`z-index:-1` 沉于内容之下、浮于页面底色之上；
  2. `.hero-portrait`：首页 Hero 右侧插画，高度 138% 超出裁切，不透明度 15%（移动端降为 10% 防拥挤）。
- **暗色主题适配**：`filter: invert(.92)` 反转为浅色墨线，不透明度略升至 8.5%/17%，保证暗底可见。
- 原则：仅作氛围装饰、永不遮挡文字（均 `pointer-events:none`）；新页面默认可直接沿用 `.ink-watermark`。

### 2.4b 质感与动效增强（v1.2 新增）

- **纸面颗粒**：`body::before` 固定的 SVG `feTurbulence` 噪点层（160px 平铺，亮色 multiply 4.5% / 暗色 screen 5%），全站"宣纸"颗粒感，`pointer-events:none`。
- **顶栏**：`::after` 朱→金→透明渐变细线收边；Logo 换为朱砂印章徽标 `.brand-seal`（白文方印、微倾斜、悬停回正放大）。
- **首页 Hero**：资料徽章带 `.hero-badges`；标题关键词朱色"笔刷下划线"（`background` 半遮渐变）；马克思名言引言带 `.hero-quote`（金线左栏+衬线体，内容为《关于费尔巴哈的提纲》第十一条）。
- **统计瓦片/功能卡**：`.stat-tile .num` 朱金渐变文字+悬停上浮；`.feature-card::before` 悬停顶部光带、图标旋转缩放。
- **闯关引导**：当前待攻关卡自动加 `.next` —— 节点填朱 + `pulseRing` 光环脉冲 + 卡片红边投影。
- **题卡**：`.q-card::before` 左侧朱金细缨；主按钮改朱红渐变+投影（`:active` 压缩回弹）。
- **全局**：路由入场 `viewIn` 逐层上浮动效（前 5 个子元素错峰 40ms 延迟）；暖色定制滚动条；`:focus-visible` 金色描边（无障碍）；页脚三星装饰线；toast 毛玻璃+金边。

- 交互均可用键盘 Tab 触达（button 原生聚焦）；导图提供按钮式缩放（不依赖滚轮）。

```

│   ├── mindmap.js        # 思维导图：SVG 树布局、缩放平移、折展、节点导读与刷题跳转
│   ├── challenge.js      # 闯关：关卡配置 LEVELS、解锁与星级规则、关卡地图渲染
│   ├── wrongbook.js      # 错题本：筛选/重做/标记掌握/整卷重练
│   └── stats.js          # 成绩分析：指标计算 + 手写 SVG 图表 + 数据导出/清空
├── data/                 # ★ 由脚本生成，勿手改
│   ├── questions.json    # 125 道客观题（判断1/单选83/多选41）
│   ├── subjective.json   # 7 道主观题（简答3/辨析2/论述1/材料论述1）
│   ├── chapters.json     # 思维导图知识树（含节点笔记）
│   ├── banks.json        # 题库索引（分组/说明/题量）
│   └── offline-data.js   # 普通脚本，赋值 window.MAYUAN_DATA，支持 file://
├── tools/
│   ├── parse_sources.py  # Markdown→JSON 流水线（README 约定的"最后统一转 JSON"）
│   ├── mindmap_source.py # 标题、列表、正文与过程关系的完整导图解析
│   └── build_offline.py  # 同步生成文件夹数据脚本和 Offline 单文件成品
├── DOCUMENTATION.md      # 本文件
└── README.md             # 项目速览与启动方式
```

### 3.2 单页路由（hash 路由，无刷新）

| 路由 | 视图函数 | 页面 |
|---|---|---|
| `#/` | `Views.home` (app.js) | 首页仪表盘 |
| `#/map` | `Views.map` (mindmap.js) | 思维导图 |
| `#/practice` | `Views.practice` (app.js) | 顺序刷题选题页 |
| `#/challenge` | `Views.challenge` (challenge.js) | 关卡地图 |
| `#/wrong` | `Views.wrong` (wrongbook.js) | 错题本 |
| `#/stats` | `Views.stats` (stats.js) | 成绩分析 |
| `#/subjective` | `Views.subjective` (app.js) | 主观题精讲 |
| `#/about` | `Views.about` (app.js) | 设计理念摘要 |

约定：各模块只向全局注册 `Views.<name>` 与少量纯函数（`startQuiz`、`pickQuestions`、`LEVELS`），不互相 import；`offline-data.js` 先加载，`app.js` 创建内核，业务模块随后注册，`DOMContentLoaded` 后启动。**新增页面 = 新建 js 文件注册 `Views.x` + index.html 加 script 标签 + 导航加链接。**

### 3.3 数据流

```
mindmap/ + questions/ ──parse_sources.py──▶ data/*.json
                        └─build_offline.py─▶ offline-data.js ──▶ DB（内存）
                                          └─▶ Offline/马原研习社.html（全部资源内嵌）
                                                    │
用户作答 ◀── quiz.js/challenge.js ──┤
        └──▶ Store.recordAnswer ──▶ localStorage ──▶ stats/wrongbook/mindmap 读取渲染
```

- `pickQuestions(filter)` 是**万能选题器**：`{banks, kySections, tag, random}` 四参数，练习/闯关/导图跳转/薄弱点训练全部复用同一入口。
- 判分规则：**多选必须全对得分（少选多选均不得分）**，与期末卷判分标准一致；未作答按错误计。

## 4. 特性详述（特性）

> 图例：✅ v1.0 已实装 ｜ 🆕 本次在基础需求上新增的特性

### 4.1 首页仪表盘 ✅

- Hero 区：产品叙事 + 四个主 CTA（闯关/导图/刷题/设计理念）。
- 学习数字条：**连续学习天数**（从今天/昨天起向前连续有作答的天数）、累计作答、总正确率、闯关总星数。
- 「继续学习」三卡：下一关推荐、错题待攻克数、导图入口——数据实时来自存档。
- 功能矩阵六卡导航。

### 4.2 完整知识图谱 ✅

- **唯一内容来源**：工程 `mindmap/chapter-01.md`。标题、嵌套无序/有序列表和正文均解析入树；每个知识节点保留自己的原 Markdown 行与源行号，取消 40 条截断，不凭空补充教材内容。
- **层级规范化**：物质下面同为 `###` 的三个编号小节规范为其子节点；辩证思维方法下面缩进不规范的四种方法归入对应任务；“不断增强思维能力”的重复源序号只在显示标签中移除，原文仍保留。
- **浏览**：分支聚焦、全文搜索并展开定位路径、多行 SVG 标签、折叠展开、平移缩放与适应画布；目录阅读模式采用嵌套折叠结构，适合窄屏与长文本。
- **节点详情**：路径、完整原文、下级知识点入口、源笔记行号及关联练习。
- **关系表达**：知识树连线仅表示内容层级；原笔记两段 Mermaid 记录为关系示意数据，由原生 HTML/CSS/SVG 表达量变质变及否定之否定过程，不依赖联网渲染器。
- **关联练习**：按所属知识分支与明确知识范围匹配练习；统计称为“关联练习正确率”，不把题库作答比例等同于具体知识点掌握程度。

### 4.3 闯关模式 ✅🆕（新增特性，重点记录）

- **关卡表 `LEVELS`（challenge.js）**：10 关线性递进，每关的 `filter` 复用万能选题器：

  | # | 关卡 | 范围 | 题量* |
  |---|---|---|---|
  | 1 | 哲学起航 | 课堂小测1 | 10 |
  | 2 | 物质与意识 | 课堂小测2 | 8 |
  | 3 | 辩证之法 | 第一章第二&三节 | 21 |
  | 4 | 期末试炼 | 2024秋期末客观题 | 15 |
  | 5 | 考研·本体论 | 绪论/物质性/规律与能动性 | 21 |
  | 6 | 考研·辩证法 | 三大规律/联系和发展 | 16 |
  | 7 | 考研·认识论 | 认识和实践/真理 | 10 |
  | 8 | 考研·历史观 | 历史唯物主义全部 | 27 |
  | 9 | 考研·政经初探 | 政治经济学 | 2 |
  | 10 | 终极挑战 | 全题库随机 20 题混编 | 20 |

  *题量在渲染时由 `pickQuestions` 实算，素材扩充后自动跟进，无需改文案。

- **作答形态**：exam 考试模式——答题卡题号跳转、未答提示、交卷确认，模拟真实考试。
- **评星与解锁规则**（硬约定，改动机需全队知晓）：
  - 正确率 ≥60% → ★ 并**解锁下一关**；≥85% → ★★；=100% → ★★★；
  - 星级与最佳正确率取历史最佳；关卡可无限重刷；
  - 全部通关后全图解锁，可回头刷满星。
- **结果反馈**：成绩环 + 星级 + 差异化文案（通关提示下一关名 / 未通关建议回导图补漏）+ 逐题回顾（只看错题/全部回顾）。

### 4.4 错题本 ✅🆕（新增特性）

- **自动归集**：任意模式（练习/考试/主观自评）答错即入册，`count` 记录累计错误次数，入册时间保留。
- **掌握闭环**：在错题重练中答对可点「标记掌握」；**整卷重练满分时整批自动标记掌握**；掌握条目保留但置灰沉淀（Tab：待攻克/已掌握/全部）。
- **筛选与操作**：按题库下拉筛选；单题重做、手动移除。
- **联动**：答对已在册的题目不会自动出册（需用户确认掌握），答错会重置掌握状态并累加计数——防止"蒙对一次就算会"。

### 4.5 成绩分析 ✅🆕（新增特性）

指标口径（全部基于 `attempts`/`sessions`，主观自评不计入正确率）：

| 图表 | 口径 |
|---|---|
| 总览五卡 | 累计作答 / 总正确率 / 连续学习天数 / 闯关进度与总星 / 待攻克错题 |
| 近14天趋势 | 每日作答柱（朱红=答对，浅红=总量），悬停 title 给明细；纵轴按峰值等分 |
| 题型正确率 | 判断/单选/多选三柱（金/红/蓝），无数据时 15% 透明度占位显示"–" |
| 题库正确率 | 五大题库横条 + "n 次作答"，未开始显示"未开始" |
| 薄弱知识点 TOP5 | 按"考研=章节、其余=题库"聚合，**样本≥3 次作答才上榜**，按正确率升序取前 5；一键针对训练（混编≤20题） |
| 成绩记录 | 最近 8 条 session：时间/内容/模式/成绩(含星级)/用时 |

- **数据管理**：导出全部存档为 JSON 备份、导入新旧格式备份（校验后确认覆盖）、确认后清空学习记录。导入过滤已不在当前题库中的题号。

### 4.6 顺序刷题 ✅

- 选题页按分组（课堂小测/期末真题/考研真题）展示题库卡：题量、已练数、最近正确率、完成进度条；支持**顺序/随机**两种练习。
- 考研真题额外提供**按章节专练**（12 个章节 chip 直达）。
- practice 模式：单选/判断点选即判、多选选完点提交；判分后锁定、正误着色、展开解析；支持回看上一题。

### 4.7 主观题精讲 ✅

- 简答/辨析/论述/材料论述四类，`prompt`（材料）折叠展示，参考答案与评分要点一键显隐。
- **自评闭环**：「我掌握了」计正确并移出错题本；「还需努力」计错误并收入错题本（qid 前缀 `S:`，错题本内仅提供"去复习"跳回）。

### 4.8 其他 ✅

- 亮/暗主题切换（顶栏 ☾/☀，持久化）。
- 空态/加载态/离线数据缺失提示；本地存储不可用时持续提示并保持本次练习可用。
- 全部动效遵守 `prefers-reduced-motion`。

## 5. 数据结构约定

### 5.1 `questions.json`（客观题）

```jsonc
{
  "id": "ky-001",              // 全局唯一：小测 c1s1-q1-01 / 期末 final24-s01 / 考研 ky-001
  "bank": "kaoyan",            // 题库 id（见 banks.json）
  "bankName": "考研政治真题精选",
  "num": 1,                    // 源文件中题号
  "type": "single",            // judge | single | multi
  "stem": "题干……",
  "options": [ { "key":"A", "text":"……" } ],   // 判断题固定 A=正确 B=错误；多选可有 E
  "answer": ["A"],             // 字母数组，多选为多字母
  "analysis": "解析全文（markdown 轻语法）",
  "tags": ["一、马克思主义哲学", "绪论……"],     // 考研题另带 part/section/subsection
  "origin": "考研真题 · 2010年第1题"            // 题源展示文案
}
```

### 5.2 `subjective.json`（主观题）

`{id, bank, kind(简答题/辨析题/论述题/材料论述题), score, title, prompt(材料,可空), reference(参考答案), rubric(评分要点/解析)}`

### 5.3 `chapters.json`（思维导图）

`{id:"root.2.3", title, level:2, kind:"heading"|"concept"|"detail", notes:[原Markdown行], children:[...], source:{file,line,endLine}, diagrams?:[{type,title,source}]}`。`level` 表示规范化后的树深度，根为 0；`source` 可追溯原资料。根 `metadata` 记录节点数、有效文本行数和关系图数量。生成时不丢弃正文或以定长摘要替代原文。

### 5.4 `banks.json`

`{id, name, group(课堂小测/期末真题/考研真题), desc, count}`

### 5.5 闯关关卡配置（challenge.js `LEVELS`）

`{id, name, sub, intro, filter}`；`filter` 三选一：`{banks:[...]}`、`{kySections:[关键词]}`（对 section/part 做包含匹配）、`{random:N}`。
**新增关卡 = 往数组里加一项**，解锁/星级/UI 全自动。

## 6. 数据流水线：Markdown → JSON

```bash
python Web/tools/build_offline.py  # 在工程根目录，同步重建数据与两种离线版本
python Web/tools/build_offline.py --skip-sources  # 仅打包当前 JSON 与网页代码
```

- 四个解析器分别对应四类素材格式（各种"答案：B/正确答案：B/参考答案：B"、"解析：/解析**："等变体均已兼容）；解析不完整（缺答案/题干/选项）的题会在运行输出中点名。
- **新增题库**：把新 md 放入 `questions` 对应目录，在 `SOURCE_FILES` 注册路径、添加解析器并在 `main()` 汇总、`banks` 登记题库；如需入闯关则加一条 `LEVELS`。
- **新增导图内容**：按知识关系维护 `mindmap/chapter-01.md` 的标题和列表缩进，重新运行构建命令。当前支持该章资料；增加其他独立章节文件时需扩展解析入口。
- **离线产物**：`offline-data.js` 将四份数据直接赋值给 `window.MAYUAN_DATA`；单文件将同一份页面的 CSS、脚本、数据和 PNG 内嵌，图片只编码一次，由首页复用。维护者需要 Python，最终使用者只需要浏览器。
- **安全内嵌**：数据脚本将 `<`、Unicode 换行分隔符转义，避免源笔记中的文本提前闭合脚本标签。单文件生成后检查是否残留外部脚本、图片或样式引用。

## 8. 已知限制与注意事项

- 数据保存在**当前浏览器** localStorage；`file://` 在不同浏览器、文件路径或隐私设置下行为可能不同，文件夹版与单文件版也不承诺共享存档。清理缓存、移动文件或换版本前请导出，之后导入；保存失败时使用内存并提示。
- HTTP 旧版导出的裸存档可导入；新版导出格式为 `{format:"mayuan.study.backup",version:1,exportedAt:ISO日期,data:Store.data}`。导入限制 10 MB、验证字段和数值、拒绝危险对象键，覆盖前确认。
- `Store.save()` / `Store.replace(data)` / `Store.reset()` 返回是否持久保存成功。reset 清空学习数据并保留主题；任何存储失败不得阻断作答。
- 导图原文使用轻 Markdown 渲染；当前两段 Mermaid 有原生关系图实现，暂不支持任意 Mermaid 语法、图片或表格自动转换。
- 期末卷为**回忆版**（数据源声明）：个别题干为回忆替代，解析非官方，页面页脚与关于页均已注明"公益复习、禁止售卖"。
- 浏览器兼容：使用了 `color-mix()`、SVG、`fetch`、optional chaining——目标为近两年主流浏览器。
