# 马原研习社 · 马克思主义基本原理学习平台

以「动态思维导图」为纲领的纯静态学习网站：思维导图 + 顺序刷题 + **闯关模式** + **错题本** + **成绩分析** + 主观题精讲。

## 快速开始

```bash
cd mayuan-study
python3 -m http.server 8000 --bind 0.0.0.0
# 浏览器打开 http://localhost:8000
```

> 必须经 HTTP 访问（页面要 fetch `data/*.json`），双击 `index.html` 无法加载题库。

## 素材更新

```bash
python3 tools/parse_sources.py   # 由 uploads/*.md 重新生成 data/*.json
```
